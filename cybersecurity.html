Secure Document Processor — RSA Encryption & Digital Signatures

An interactive Java command-line project that protects a local training message with RSA encryption, then signs and verifies the original content to demonstrate confidentiality, integrity, authenticity, and tamper detection.

What it does: Generates an RSA-2048 key pair, encrypts and decrypts the message, creates a SHA-256 with RSA signature, verifies the signature, and proves that modified content fails verification.

Security practice: Private keys and generated encrypted/signature artifacts are excluded from the public repository. The project uses fictional training content and is presented as an educational demonstration.

Hybrid AES-RSA Secure Communication System

An interactive Java command-line project demonstrating hybrid encryption end to end. It encrypts a message with a randomly generated AES session key, uses RSA modular arithmetic to protect that key, reconstructs it, and verifies decryption.

Concepts demonstrated: AES-128 encryption, IV generation with SecureRandom, RSA key mathematics, modular inverses, and byte-to-hexadecimal transformations.

Educational focus: The program deliberately displays intermediate values so the hybrid-encryption workflow is visible. It is a learning demonstration, not a production cryptography system.
